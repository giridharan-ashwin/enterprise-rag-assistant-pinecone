# Synthetic Enterprise Policy — Security Incident

## Incident Reporting
Employees should report suspected security incidents through the security incident portal. Urgent incidents should also be called in to the security response team.

## Incident Severity
Security incidents are categorized by business impact and data exposure. High-severity incidents receive immediate response coordination.

## Evidence Preservation
Employees should not delete or modify potentially relevant logs or files during an investigation. The security response team coordinates evidence preservation.

## Incident Escalation
High-severity incidents are escalated to the security leadership team. Customer-impacting incidents also require communications review.

## Post-Incident Review
Significant incidents receive a documented post-incident review covering root cause, corrective actions, and follow-up owners.
