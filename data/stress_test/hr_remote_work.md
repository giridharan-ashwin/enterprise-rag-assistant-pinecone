# Synthetic Enterprise Policy — Hr Remote Work

## Remote Work Schedule
Employees may work remotely up to three days per week. Teams may designate collaboration days when in-person coordination is needed.

## Remote Work Approval
Remote work arrangements require manager approval. Long-term changes to a regular work pattern should be reviewed by the department lead.

## Remote Equipment
The company provides a standard laptop and security software for approved remote workers. Employees are responsible for maintaining a secure home network.

## Remote Collaboration
Remote teams should use the approved collaboration platform for team meetings and project communication. Critical meetings may require video participation.

## Remote Work Security
Remote workers must use multi-factor authentication and the company virtual private network when accessing protected internal systems.
